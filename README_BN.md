# সেটআপ গাইড (কোন ফাইল কোথায় যাবে)

## ফোল্ডার
- `supabase/schema.sql` → Supabase এর SQL Editor-এ পেস্ট করে Run করবেন (ডাটাবেস + সিকিউরিটি রুলস)
- `web/config.js` → আপনার Supabase URL ও anon key বসাবেন
- `web/index.html` → কাস্টমার অ্যাপ
- `web/vendor.html` → দোকানদার প্যানেল
- `web/admin.html` → অ্যাডমিন প্যানেল
- `web/app.js` → সবার কমন কোড

## ধাপে ধাপে
1. supabase.com এ ফ্রি প্রজেক্ট খুলুন। Project Settings > API থেকে URL ও anon key কপি করুন → `web/config.js` এ বসান।
2. SQL Editor এ `schema.sql` পুরোটা Run করুন।
3. Storage > New bucket → নাম `images`, **Public** করুন। (ছবি আপলোডের জন্য; Policies এ authenticated users কে INSERT দিন)
4. Authentication > Providers > Email: টেস্টের জন্য "Confirm email" বন্ধ রাখতে পারেন।
5. GitHub এ নতুন রিপোজিটরি খুলে `web` ফোল্ডারের ফাইলগুলো আপলোড করুন → Settings > Pages থেকে ফ্রিতে হোস্ট হবে।
6. `index.html` এ কাস্টমার হিসেবে সাইন আপ করুন। `vendor.html` এ দোকানদার হিসেবে সাইন আপ করে দোকান রেজিস্টার করুন।
7. নিজেকে অ্যাডমিন বানাতে `admin.html` এ সাইন আপ করে SQL Editor এ schema.sql এর নিচের কমেন্টের `update profiles set role='admin'...` লাইনটি আপনার ইমেইল দিয়ে Run করুন। তারপর admin.html থেকে দোকান Verify করুন।

## এই ভার্সনে যা কাজ করে
ডুয়াল ল্যাঙ্গুয়েজ (মূল বাটন/লেবেল), এলাকা সিলেক্ট + GPS ডিটেক্ট, টেক্সট ও ভয়েস সার্চ, লোকাল/All Bangladesh/Offers ট্যাব, Sold Out, কার্ট, কুপন, ফ্ল্যাট ডেলিভারি চার্জ, চার্জ বাড়ালে কাস্টমার কনফার্মেশন, ফটোসহ রিভিউ (ভেন্ডর এডিট/ডিলিট করতে পারে না), রিভিউ রিপোর্ট ও অ্যাডমিন রিমুভ, দোকান ভেরিফিকেশন (NID + ছবি), ভেন্ডর অ্যানালিটিক্স, অ্যাডমিন সেলস/কমিশন/জোন চার্জ।

## এখনো বাকি (পরবর্তী ধাপ, সৎভাবে বলছি)
- বিকাশ/নগদ/কার্ড পেমেন্ট গেটওয়ে (মার্চেন্ট অ্যাকাউন্ট ও API লাগবে; এখন শুধু COD সম্পূর্ণ কাজ করে)
- ডিজিটাল ওয়ালেট, ফ্ল্যাশ সেল টাইমার
- রাইডার অ্যাপ ও লাইভ ট্র্যাকিং, রাইড-শেয়ারিং
- কুরিয়ার API ইন্টিগ্রেশন (এখন শুধু ফ্ল্যাট ফি)
- পুশ নোটিফিকেশন (এখন অর্ডার পেজে স্ট্যাটাস দেখা যায়)
- সাপোর্ট টিকেট, সম্পূর্ণ বাংলা অনুবাদ
- Android/iOS অ্যাপ (এটি মোবাইল-ফ্রেন্ডলি ওয়েব অ্যাপ; পরে PWA বা Flutter/React Native এ নেওয়া যাবে)
- ভেন্ডর প্যানেলে "রিভিউ রিপোর্ট" বাটন (ডাটাবেস রেডি, UI বাকি)

## কোম্পানির নাম, লোগো ও ব্যানার
`web/config.js` ফাইলের নিচে `BRAND_NAME`, `LOGO_URL`, `BANNER_URL` আছে। নাম বদলান এবং আপনার `logo.png` ও `banner.jpg` ফাইল `web` ফোল্ডারে রাখুন। তিনটি পেজেই (কাস্টমার, ভেন্ডর, অ্যাডমিন) উপরে এটি দেখাবে।
